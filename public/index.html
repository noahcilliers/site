    How it works

    The board above has no special access. It holds one seat's token and makes moves through the same public API your opponent uses.

    1. BoardYou drag a piece. The page sends POST /moves with your seat token.
    2. APIThe HTTP layer checks the token and passes the move on.
    3. GameThe rules engine checks it against every legal move and updates the position.
    4. OpponentAnyone waiting on the game gets the new position and replies the same way.
    POST /api/games
    Start a game and get a token for each seat
    GET /api/games/:id
    Board, legal moves and history. Add ?since= to wait for the next move
    POST /api/games/:id/moves
    Play a move like e7e5
    POST /api/games/:id/resign
    Resign your seat
